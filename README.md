# Ziro

The website for Ziro: your music, as a live lyric video, word for word with the song.

**Live at https://iksamxul.github.io/Ziro/**

This repository holds the built site that GitHub Pages serves. The installers for Windows and Android
will be on the [releases page](https://github.com/iksamxul/Ziro/releases); the site's download buttons
pick up the latest release by themselves.

Lyrics in Ziro come from [LRCLIB](https://lrclib.net). Typefaces from
[Fontsource](https://fontsource.org) under the SIL Open Font License.
